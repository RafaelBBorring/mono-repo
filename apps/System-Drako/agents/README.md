# Agentes do System-Drako

Seis agentes especializados, cada um dono de sua área. Acione conforme a tarefa.

| Agente | Arquivo | Quando acionar |
|---|---|---|
| **CEO** | [agente-ceo.md](./agente-ceo.md) | Visão, escopo, priorização, conflitos entre áreas, aprovação final. |
| **Design** | [agente-design.md](./agente-design.md) | Identidade visual, estética, paleta, tipografia, motion, glassmorphism. |
| **Regras do Sistema** | [agente-regras.md](./agente-regras.md) | Fidelidade ao documento do RPG, atributos, recursos, combate, magia, morte. |
| **Balanceamento** | [agente-balanceamento.md](./agente-balanceamento.md) | Integridade matemática, custo-benefício de energia, tetos, auditoria de habilidades. |
| **UI** | [agente-ui.md](./agente-ui.md) | Layout, fluxo, componentes, micro-interações, acessibilidade, estados. |
| **Desenvolvimento** | [agente-desenvolvimento.md](./agente-desenvolvimento.md) | Arquitetura, código, build, performance, deploy, bug-fix. |

## Fluxo típico de um recurso novo
1. **CEO** define o "quê" e aprova o escopo.
2. **Design** + **UI** desenham a experiência.
3. **Regras** valida a mecânica; **Balanceamento** calibra números.
4. **Desenvolvimento** implementa (build verde obrigatória).
5. **CEO** assina a entrega final.

## Princípio comum
Servir ao usuário-alvo: **o Mestre que precisa criar muitos NPCs, rápido, com beleza e confiança.**
